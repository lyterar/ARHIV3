# Research: NASA NEO Tracker

## Decision: Стандартная библиотека Python и Tkinter

**Rationale**: Пользовательский стек явно ограничен Python 3.11+, `tkinter`/`ttk`,
`urllib.request`, `json`, `datetime`, `unittest` и `unittest.mock`. Это
удовлетворяет требованию отсутствия сторонних зависимостей и оставляет
тестируемые границы между GUI и логикой.

**Alternatives considered**: сторонние HTTP-клиенты, GUI-фреймворки и тестовые
фреймворки не используются, поскольку нарушили бы заданное ограничение.

## Decision: Один запрос NASA NeoWs Feed на выбранный день

**Rationale**: Endpoint `/neo/rest/v1/feed` принимает `start_date` и `end_date`.
Одинаковые значения ограничивают выдачу ровно одним днём. Параметр `api_key`
получается из `NASA_API_KEY`; при его отсутствии допускается `DEMO_KEY`.

**Alternatives considered**: диапазон дат и случайный выбор первой записи
отклонены: они нарушают требование не подставлять данные другого дня.

## Decision: Строгий parser с нормализацией в доменную модель

**Rationale**: NASA JSON имеет вложенные структуры и значения строкового типа
для скорости/расстояния. Парсер проверяет ожидаемые контейнеры, выбирает ключ
выбранной даты и конкретную запись `close_approach_data` с совпадающим
`close_approach_date`, затем преобразует поля в понятные единицы.

**Alternatives considered**: отображение сырого JSON отклонено, потому что
смешивает формат API с GUI и не позволяет гарантировать единицы и отсутствие
подмены даты.

## Decision: Последний пригодный кэш в JSON с атомарной заменой

**Rationale**: JSON читается стандартной библиотекой, содержит версию формата,
дату данных, время получения и строки таблицы. Временный файл создаётся рядом
с целевым, затем заменяется через `os.replace`, поэтому недописанный ответ не
заменяет пригодный кэш.

**Alternatives considered**: база данных и несколько исторических файлов
избыточны для требования хранить только последний успешный набор.

## Decision: Рабочий поток + queue + Tkinter.after

**Rationale**: `urllib.request.urlopen` с конечным timeout не выполняется в
главном потоке. Worker помещает ровно один результат операции в `queue.Queue`,
а GUI периодически забирает его через `after`; все изменения Tkinter выполняются
в главном потоке.

**Alternatives considered**: прямой вызов из callback кнопки отклонён как
блокирующий; `asyncio` не выбран, поскольку он усложняет простой Tkinter-проект.

## Explicit ambiguities and proposed defaults

1. **Путь кэша** зафиксирован для Windows:
   `%LOCALAPPDATA%\NASA-NEO-Tracker\cache.json`. Каталог создаётся
   автоматически, а тесты передают временный путь.
2. **Тайм-аут** зафиксирован в 15 секунд. После ошибки состояние GUI
   возвращается в рабочее состояние и разрешает ручной повтор.
3. **Неполные записи** обрабатываются по явным правилам: запись без названия
   или без сближения за выбранную дату пропускается с предупреждением; числовые
   пропуски отображаются как «Нет данных»; отсутствующий hazard-флаг — как
   «Неизвестно». Нули не подставляются. Если пригодных записей не осталось,
   применяется fallback кэша.
4. **Fallback `DEMO_KEY`** сопровождается фиксированным уведомлением без
   показа значения ключа. HTTP 429 даёт понятное сообщение и запускает fallback
   кэша с возможностью повторить запрос.
