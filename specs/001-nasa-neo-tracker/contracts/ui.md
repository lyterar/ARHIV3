# User Interface Contract

## Controls

- Поле даты: `YYYY-MM-DD`, начальное значение — текущая локальная дата.
- Кнопка `Получить данные`: активна только для валидной даты и вне загрузки.
- Индикатор загрузки: видим в состоянии `loading`.
- Таблица: колонки из [api.md](./api.md).
- Область статуса: успех, ошибка, предупреждение кэша и отсутствие данных.
- После ошибки, тайм-аута или HTTP 429 кнопка снова доступна для ручного
  повторения запроса.

## Metadata

Каждое состояние с данными показывает выбранную дату, фактическую дату
показанных данных, `NASA NeoWs` как источник, время получения ответа и явную
отметку `свежие данные` или `данные из кэша`.

При кэше выбранная дата не изменяется на дату кэша. При отсутствии данных
таблица не заполняется фиктивными строками.

Числовая ячейка без значения показывает «Нет данных». Отсутствующий признак
опасности показывает «Неизвестно». Запись без названия или без сближения за
выбранную дату пропускается с предупреждением. При использовании `DEMO_KEY`
показывается уведомление:
«Используется демонстрационный ключ NASA с ограниченной квотой. Для регулярной
работы настройте NASA_API_KEY». Значение ключа не отображается.

## Threading contract

Callback кнопки выполняет только валидацию и запуск worker. Worker не вызывает
Tkinter напрямую и возвращает один объект результата через `queue.Queue`.
Главный поток получает результат через `after`, меняет виджеты, выключает
индикатор и обновляет таблицу.
