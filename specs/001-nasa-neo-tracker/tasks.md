# Tasks: NASA NEO Tracker

**Input**: Design documents from
`/specs/001-nasa-neo-tracker/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md),
[research.md](./research.md), [data-model.md](./data-model.md),
[contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: Unit-тесты обязательны, но создаются только на TEST-этапе после
слияния реализации. Они запускаются без реального NASA API командой
`python -m unittest discover -s tests -v`.

**Task format**: `[ID] [P?] [Story/Stage] Описание — результат; файлы;
зависимости`. Все идентификаторы последовательные, без буквенных суффиксов.

## MVP and acceptance strategy

### IMPL smoke MVP

После T018 приложение должно запускаться командой `python -m src.main` и
проходить ручные smoke-проверки T017: валидная/неверная дата, загрузка,
отзывчивость, ошибки, кэш и ручной повтор. Это подтверждает работоспособность
IMPL-этапа, но не является полной приёмкой.

### Full acceptance

Полная приёмка требует завершения TEST-этапа T031 и успешного выполнения
`python -m unittest discover -s tests -v` без реального NASA API, а также
успешной ручной проверки T027.

## Definition of Done

- Выполнены T001–T031.
- SPEC, IMPL и TEST прошли отдельные ветки, коммиты, Pull Request и слияние.
- Приложение запускается командой `python -m src.main`.
- Unit-тесты запускаются командой `python -m unittest discover -s tests -v`.
- Проверены даты, NASA API, ошибки сети/HTTP/429/timeout, неполные ответы,
  отзывчивость, кэш, перезапуск и различие выбранной даты с датой кэша.
- `README.md` и `REPORT.md` содержат только фактически подтверждённые сведения.
- Финальная проверка `REPORT.md` подтверждает фактически использованные модели
  Antigravity и этапы их применения; заранее названия моделей и результаты не
  заполняются.
