# Quickstart and Validation: NASA NEO Tracker

Документ описывает проверку будущей реализации; исходный код и тесты на этом
этапе не создаются.

## Prerequisites

1. Установить Python 3.11 или новее с модулем Tkinter.
2. В рабочей среде задать `NASA_API_KEY`; для учебной проверки допускается
   `DEMO_KEY`, но он имеет ограниченную квоту. При его использовании должно
   показываться: «Используется демонстрационный ключ NASA с ограниченной квотой.
   Для регулярной работы настройте NASA_API_KEY».
3. Не добавлять ключ в репозиторий, fixtures, кэш, сообщения или командные
   файлы.

## Unit-test command

Из корня проекта:

```powershell
python -m unittest discover -s tests -v
```

Ожидается успешное завершение без сетевых обращений. Тесты должны покрывать
пустую, неверную и несуществующую дату; корректный, пустой и повреждённый NASA
JSON; выбор сближения за выбранную дату; HTTP, timeout и сетевую ошибку через
mock; запись, чтение, повреждение и сохранение старого кэша через временный
каталог.

## Manual GUI scenarios

1. Запустить приложение и убедиться, что поле содержит текущую локальную дату.
2. Ввести `2026-02-31`: кнопка отключена, сетевой вызов не выполняется.
3. Ввести существующую дату и получить корректный ответ: проверить все 6
   колонок, источник, выбранную дату, фактическую дату и время ответа.
4. Во время запроса убедиться, что окно перерисовывается и не зависает.
5. Смоделировать timeout/HTTP 429/отсутствие сети: проверить тайм-аут 15 секунд,
   предупреждение, показ последнего кэша либо сообщение об отсутствии кэша и
   доступность кнопки для ручного повтора.
6. Смоделировать пустой/повреждённый ответ: проверить, что старый кэш
   сохраняется и не показывается как данные выбранной даты.
7. Закрыть и повторно открыть приложение: проверить восстановление даты,
   времени и строк последнего успешного набора.
8. На Windows проверить файл `%LOCALAPPDATA%\NASA-NEO-Tracker\cache.json`;
   в unit-тестах проверить подмену пути временным каталогом.
9. Проверить неполные записи: пропуск без названия/сближения с предупреждением,
   «Нет данных» для числового пропуска и «Неизвестно» для hazard-флага; при
   отсутствии пригодных строк проверить fallback кэша.
